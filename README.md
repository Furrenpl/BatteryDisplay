# BatteryDisplay

Приложение для Windows 10/11 x64: заряд и состояние беспроводных устройств рядом с системным треем.

## Установка

Откройте `releases/BatteryDisplay-1.0.0-x64.msi`. Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\BatteryDisplay`. Среда .NET включена в установщик; отдельно скачивать её не нужно.

На странице выбора компонентов доступен **«Автозапуск при входе в Windows»**. По умолчанию он отключён. Чтобы включить его, нажмите значок рядом с компонентом и выберите установку на локальный диск. После установки запускайте приложение из меню **Пуск → BatteryDisplay**. Для изменения автозапуска повторно откройте MSI и выберите изменение компонентов.

Перед установкой обновления закройте BatteryDisplay через **Выход** в меню трея. Удаление доступно через установленные приложения Windows или повторный запуск MSI. При удалении убираются приложение, ярлык и запись автозапуска; пользовательские настройки сохраняются.

## Настройки

ПКМ по значку в трее или оверлею → **Настройки**. Выберите устройства, их типы, мониторы, положение оверлея и частоту опроса (5–3600 секунд). Нажмите **Сохранить**. Параметры загружаются при каждом запуске, в том числе после входа в Windows.

Настройки: `%LOCALAPPDATA%\BatteryDisplay\settings.json`. Этот файл не входит в MSI и не заменяется при обновлении. Для полного сброса закройте приложение и удалите файл вручную.

- 70–100% — зелёный; 31–69% — жёлтый; 0–30% — красный.
- Без процента показывается только иконка. Зелёная означает подтверждённое подключение, серая — отключение или неизвестное состояние. Подробности доступны в подсказке.
- Оверлей привязывается к левому краю трея основного монитора. На мониторах без трея используется настраиваемый отступ. Оверлей не резервирует место в панели задач.

## Поддержка устройств

- Bluetooth: заряд из свойств Windows; для классического Bluetooth проверяется активное соединение. Полноценное определение соединения BLE пока не реализовано, поэтому неподтверждённый кэшированный процент BLE скрывается.
- AJAZZ AJ159 Apex, приёмник `3151:5007`: запрос телеметрии HID.
- AULA F108 Pro, приёмник `05AC:024F`: запрос батареи HID.
- Геймпады XInput: обнаружение подключения и доступной категории заряда. Приёмник может сообщать проводное питание вместо процента.
- Приёмник 8BitDo `2DC8:301C`: обнаружение; собственный протокол батареи не реализован.

Ответы зависят от прошивки, режима подключения и состояния устройства. Наличие донгла не доказывает активное соединение. Для неподдерживаемых приёмников универсального способа чтения заряда нет.

## Сборка

Требуются Windows и .NET SDK 10. Выполните из PowerShell:

```powershell
.\build-installer.ps1
```

Скрипт загружает WiX 5.0.2, расширение интерфейса и компоненты .NET, собирает автономное приложение и MSI. Интернет нужен только для загрузки зависимостей. Результат — `releases/BatteryDisplay-1.0.0-x64.msi`. Временные файлы находятся в `.build`, `bin`, `obj`; их можно удалить после сборки.

Для следующей версии обновите номер в `BatteryDisplay.csproj`, `installer/Package.wxs` и имени результата в `build-installer.ps1`. Сохраняйте UpgradeCode установщика: он обеспечивает обновление предыдущих версий.
